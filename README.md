# Academic Anxiety Platform

A student wellness app for managing academic anxiety — calm mode, study companion, action plans, and campus resources.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Push this repo to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repository.
3. Vercel auto-detects Next.js — click **Deploy** (no env vars required).
4. Share the live URL with your group.

## Tech stack

- Next.js 16
- React 19
- Tailwind CSS 4
- shadcn/ui
